## Behavior and rationale

Nine operations expose the actual Case engine: creation, original-file collection, private timeline, verification, custody assertion, checkpoint, minimized timeline, private selection template and selected-event handoff. The UI supports review without commands while preserving original source lines, true page denominators and explicit privacy boundaries. Prepared fictional access/service files enter the same controls and core; they are not precomputed results or host data.

An imported-database availability gap was corrected: application-table queries could encounter hostile views before full provenance verification. SQLite's own ordinary-table classification, bounded row fetches, length and connection VM limits now precede review. Real recursive-view, comment-spelled virtual-table, oversized-cell and expensive-query fixtures reject. Original case/CLI transactions remain supported. This does not assert database payload execution or forensic certification.

## Limits

The package is a Windows portable EXE, not a signed installer. Tests do not use a normal user profile, account, real host log, remote source, Docker service or installed shortcut. Original cases and private timeline/checkpoint/template bundles remain sensitive plaintext. Handoffs are pseudonymized, not anonymous. Clocks/operators remain assertions; same-profile checkpoints are not independent storage; a fully unanchored rewrite by the OS owner is outside the guarantee. Case and later GUI-history commits remain separate and require Verify after uncertain storage failure. No raw original BLOB is duplicated into GUI history or automatically deleted.
