# Security policy

Created by Jason Stys. This local defensive lab must only process specifically authorized evidence. Original files, databases, operator/source mappings and checkpoints are private; do not attach them to GitHub issues. Public examples use reserved `.invalid` names/documentation IPs and fictional events. No actual passwords/tokens/customer data are required.

Use [GitHub contact](https://github.com/JasonStys) or [LinkedIn](https://www.linkedin.com/in/jason-stys-31b30b351/) to arrange a private disclosure channel before sending sensitive reproductions. Describe affected version/boundary and a synthetic reproduction, not raw evidence. A response-time/service guarantee is not offered by this portfolio repository.

Read [threat model](docs/threat-model.md) and [runbook](docs/runbook.md). Not a hosted multi-user app, anti-malware sandbox, encrypted vault, legal-admissibility tool or certified government control implementation. Host administrators/local privilege peers are trusted; an independent checkpoint does not authenticate source truth or future unanchored suffixes. Updates must preserve negative tests, least privilege, pinned dependencies and privacy projection; no advisory suppression or evidence deletion to obtain green checks.
